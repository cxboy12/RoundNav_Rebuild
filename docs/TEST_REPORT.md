# RoundNav Direct 验证记录

## 2026-11-24

| 项目 | 结果 |
| --- | --- |
| 电脑版源码和两端协议 | 已核对 Windows 抓屏、JPEG 参数、TCP 字段、固件接收、DMA 和统计口径。历史性能按[基准](BASELINE.md)记录。 |
| 上游版本和工程接线 | 逐项核对上游快照，除本次集成修改的四个文件外，原 128 个文件内容一致（允许换行格式差异）。核对了 Xcode 项目中的新源码引用及编译阶段。 |
| 主机协议模拟 | 用 Python、Pillow 和原 `fake_receiver.py` 的协议与解码函数，验证 16/16/20 字节报文、基线 JPEG 4:2:0 SOF 字段、拆段读取及 ACK。两种握手的物理面板均为 466×466，对齐 16 时模拟 352×352 @ (56,56)，对齐 8 时模拟 360×360 @ (52,52)。 |
| iOS 构建和编码 | Windows 环境无 Xcode。目标编译、签名、iPhone 的 ImageIO JPEG 输出及与 ESP32 的直连待验证。 |
| ESP32 构建 | ESP-IDF 5.5.6 构建通过。应用镜像 `esp32-direct/build/roundnav_direct.bin` 为 885,968 字节。esptool 确认芯片目标为 ESP32-S3，校验和及验证哈希有效。 |
| ESP32 实机 | 用户确认微雪 1.75 英寸 AMOLED，独立固件沿用 CO5300 466×466 BSP 和既有 JPEG 分块路径。现有板卡为单 factory 分区，本轮未烧录。360×360 最后一个 MCU 块的 8 行、颜色及实物画面待测试板验证。 |
| 性能与稳定性 | 10/15/20/25/30 FPS 各 10 分钟及最终 30 分钟待真机验证。还需检查 AP 地址、iPhone 地址和局域网连通性、蜂窝数据、锁屏、切换导航页、断线恢复、显示延迟和热状态。 |

主机模拟用合成纯色画面，运行路径是 Python 测试设施。OLED/LCD 实际显示帧率需单独观察和记录，软件 ACK 仅代表固件提交。

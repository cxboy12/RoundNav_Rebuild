# RoundNav Direct 验证记录

## 2026-11-24

| 项目 | 结果 |
| --- | --- |
| 电脑版源码和两端协议 | 已核对 Windows 抓屏、JPEG 参数、TCP 字段、固件接收、DMA 和统计口径。历史性能按[基准](BASELINE.md)记录。 |
| 上游版本和工程接线 | 逐项核对上游快照，除本次集成修改的四个文件外，原 128 个文件内容一致（允许换行格式差异）。核对了 Xcode 项目中的新源码引用及编译阶段。 |
| 主机协议模拟 | 用 Python、Pillow 和原 `fake_receiver.py` 的协议与解码函数，验证 16/16/20 字节报文、基线 JPEG 4:2:0 SOF 字段、拆段读取及 ACK。模拟握手分别为 466×466 对齐 16 和 360×360 对齐 8，对应 352×352 和 360×360。 |
| iOS 构建和编码 | Windows 环境无 Xcode。目标编译、签名、iPhone 的 ImageIO JPEG 输出及与 ESP32 的直连待验证。 |
| ESP32 固件与实机 | 指定源码是 CO5300 466×466。ST77916 目标板的型号、总线、引脚、初始化和实物画面待确认。现有圆屏固件未烧录。 |
| 性能与稳定性 | 10/15/20/25/30 FPS 各 10 分钟及最终 30 分钟待真机验证。还需检查 AP 地址、iPhone 地址和局域网连通性、蜂窝数据、锁屏、切换导航页、断线恢复、显示延迟和热状态。 |

主机模拟用合成纯色画面，运行路径是 Python 测试设施。OLED/LCD 实际显示帧率需单独观察和记录，软件 ACK 仅代表固件提交。

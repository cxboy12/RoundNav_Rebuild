# RoundNav Direct 内存预算

ESP32-S3 接收器以 466 像素面板宽度和 16 行块大小分配缓冲，360 像素视频共 23 块，最后一块有 8 行可见像素。

| 用途 | 存储 | 静态预算 |
| --- | --- | ---: |
| 三个 JPEG 接收槽 | PSRAM | 786,432 B |
| 一个 RGB565 解码块，按 16 字节对齐 | 内部 RAM | 14,912 B |
| 两个 RGB565 DMA 缓冲 | 内部 DMA RAM | 29,824 B |
| TCP 丢弃数据暂存 | 静态内存 | 1,460 B |
| 解码、TCP、发现任务栈 | FreeRTOS 任务内存 | 13,312 B |

另有网络栈、Wi-Fi 缓冲、JPEG 解码工作区、任务及队列开销。上述数字来自配置和分配表达式。板上峰值和最小剩余内存待测。
